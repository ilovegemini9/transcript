ClipText Chrome Extension

Save the TikTok page you're viewing by opening the extension and choosing “Add current tab”. The extension stores the URL locally and opens this workspace.

  1. Download or clone the ClipText repository.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose “Load unpacked” and select the extension folder.
  4. Open a TikTok video and click the ClipText extension icon.
View extension manifest
